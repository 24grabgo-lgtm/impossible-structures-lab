# Implementation Plan v0

## Product slice
Strip map + trilithon win + method report export.

## Build order
1. **Stone body** — mass, CoM, friction, tip stability  
2. **Socket tool** — ramp/vertical profile dig  
3. **Haul** — sled/rollers, grade, labor meter  
4. **Raise upright** — tip + A-frame + pack  
5. **Lintel** — crib **or** ramp path (one complete, second optional)  
6. **Win checks** + flag recorder  
7. **Quarry/dress** abstraction (time + fracture)  
8. **UI** — method flags, budgets, replay summary  

## Engine note
Unreal or general physics prototype both fine; start with **stable rigid bodies + constraints**, not full FEM rock fracture.

## Done when
Cold player extracts (or receives blanks), raises two uprights, seats lintel once, sees which methods they used — and failed at least once learning.

## After v0
Baalbek-mass block; precision mode; bluestone long haul; photo-mode report cards.

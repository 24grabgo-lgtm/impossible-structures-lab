# Success Metrics

**What does “someone figured it out” mean?**

---

## Primary win (trilithon PoC)

| Check | Pass condition |
|-------|----------------|
| Upright A | Within plumb tolerance; socket packed; stable under sim gravity |
| Upright B | Same; spacing matches lintel span ± tolerance |
| Lintel | Seated on both; contact ≥ threshold; does not slide under test load |
| Joints | Optional hard mode: gap ≤ player-set mm target |

Run is a **win** if all primary checks pass **with whatever method flags were enabled** — and the run records those flags.

---

## Budgets (pick scenario preset)

| Budget | Meaning |
|--------|---------|
| **Labor-time** | Person-days consumed |
| **Timber** | Crib/ramp/A-frame wood spent |
| **Rope wear** | Failures from stretch/snap |
| **Crew safety** | Injuries / crush events |
| **Anomaly** | Speculative flags cost anomaly points; 0 = pure baseline |

Presets:
- **Strict Neolithic** — baseline methods only, anomaly = 0  
- **Open lab** — all flags on, score by efficiency  
- **Precision BAM-lite** — win requires tight gap tolerance  

---

## Shareable output

Every successful run exports:
1. Method flag list  
2. Budget spent  
3. Failure count before success  
4. Short timeline (quarry → raise → lintel)  

That’s the “I figured it out” artifact — comparable across players without declaring historical truth.

---

## Fail states (legible)

- Tip past plumb / fall  
- Socket blow-out  
- Crib collapse  
- Ramp shear  
- Lintel slide  
- Rope failure under peak load  
- Labor exhaustion mid-raise  

---

*Success is physical + recorded method mix — not a lore ending.*

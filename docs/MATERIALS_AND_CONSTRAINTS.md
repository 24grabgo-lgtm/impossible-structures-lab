# Materials & Constraints

## Stone types (v0)

| Type | Role | Traits |
|------|------|--------|
| **Sarsen-analogue** | Uprights + lintel | High mass, tough, slow to dress, long local haul |
| **Bluestone-analogue** | Optional later | Smaller, longer-distance haul challenge |
| **Packing rubble** | Socket lock | Cheap, abundant, weak structurally |
| **Timber** | A-frames, cribs, rollers, rails | Consumable; wet/rot/quality tiers later |
| **Rope** | Haul / bind | Stretch, snap thresholds, wet strength |

## Physical knobs (sim)

- Mass (tonnes)  
- Center of mass  
- Friction vs ground / wood / wet clay  
- Compressive strength (crib posts, packing)  
- Fracture risk if levered on bad point  
- Dressing time vs face flatness (feeds BAM-style tolerance goals)  

## Player-facing rule

Harder stone → slower work → better load-bearing.  
Faster “cheat” extract → more fracture risk on raise.

# PoC Target — Locked

## Structure
**One trilithon:** two upright stones + one lintel.  
Success = both uprights stable + lintel seated within a tolerance band.

## Time (toolkit baseline)
Late Neolithic / Early Bronze **method set** as default (levers, sleds, ropes, timber, earth ramps, fire-water fracture optional, copper/stone tools for dressing).

Sandbox **method flags** may enable:
- Later classical machines (treadwheels, compound pulleys)
- Experimental archaeology documented techniques
- Speculative assists (vibration, abrasives, “unknown” energy) — clearly labeled **speculative**, never required

## Place
Simplified **strip map**:
1. Quarry face (extract)
2. Rough path / gradient
3. Staging flat
4. Site sockets / packing

Materials as types: **sarsen-analogue** (uprights/lintel mass class), optional **bluestone-analogue** (smaller, longer haul option for later).

## Stretch target (v0.2)
Single **Baalbek-class** block: same systems, mass scaled up, shorter “structure” (place on platform line).

## Explicit non-target for v0
Full Stonehenge circle, Puma Punku field, Giza, underwater builds.

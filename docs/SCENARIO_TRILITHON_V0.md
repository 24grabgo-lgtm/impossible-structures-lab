# Scenario — Trilithon v0

## Goal
Seat one lintel on two uprights. Export method report.

## Map strip
1. **Quarry face** — detach two upright blanks + one lintel blank  
2. **Path** — gentle grade, optional soft patch (friction spike)  
3. **Staging** — dress faces, cut tenons/mortices (simplified)  
4. **Site** — two sockets + clearance for ramp or crib  

## Beats

| Beat | Player problem |
|------|----------------|
| Extract | Wedges/fire/abrasion; avoid fracture |
| Haul upright A | Friction + grade; roller management |
| Socket A | Dig profile; tip; A-frame or pack-raise; plumb; pack |
| Haul + raise B | Spacing must match lintel |
| Dress contact | Flatness vs time |
| Lintel up | Crib **or** ramp **or** hybrid |
| Seat + test | Contact check; optional gap measure |

## Default flags ON
Ramped socket, A-frame, rollers, sled+lube, crib, earth ramp, lever-pack.

## Default flags OFF
Solo counterweight miracles, speculative anti-friction, metal winches, cranes.

## Teaching failures (scripted soft gates)
First upright: suggest A-frame if direct pull stalls.  
Lintel: if ramp footprint blocked, prompt crib — or vice versa.

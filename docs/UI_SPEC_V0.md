# UI Spec v0

## Screens

### 1. Method Flags (pre-run / pause)
- Checklist: baseline group vs experimental vs speculative
- Anomaly budget display
- Preset buttons: Strict Neolithic / Open Lab / Precision

### 2. Field HUD
- Selected stone mass + CoM marker toggle
- Labor assigned / available
- Timber / rope meters
- Active tool: dig / haul / lever / A-frame / crib / ramp
- Plumb indicator when raising

### 3. Socket view
- Cross-section: ramp angle, vertical face, depth
- Ghost of stone tip path

### 4. Win report
- Checklist uprights + lintel
- Flags used (share list)
- Budgets spent
- Failures count
- Button: copy summary / screenshot

## Tone
Field notebook + engineering, not fantasy RPG chrome.

## Non-UI
No skill trees. No loot. Methods are the loadout.

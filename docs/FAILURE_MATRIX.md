# Failure Matrix

| Stage | Failure | Player reads |
|-------|---------|--------------|
| Extract | Blank fractures | Wedges/fire too aggressive |
| Haul | Stuck / slide back | Friction, grade, rollers lost |
| Socket dig | Wrong profile | Stone won't seat / kicks out |
| Tip-in | Misses ramp | Restart position |
| Raise | Past-plumb fall | No brake / pack late |
| Raise | Rope snap | Peak load, no A-frame |
| Pack | Soft lock | Upright leans over time |
| Crib | Stack rack/collapse | Uneven lift, bad timber |
| Ramp | Shear / sink | Fill quality, angle too steep |
| Lintel seat | Slide off | Spacing/flatness/tenon fail |
| Precision mode | Gap over target | Dress more or accept anomaly |

Each failure should be **one screenshot obvious**.

# Player-Authored Techniques

**Status:** Design — the “what if I invent the method?” layer  
**Kerbal + Léo energy:** Finite physical laws; infinite legitimate assemblies of idea.

---

## 1. Why this exists

The method catalog is a **starter kit**, not a ceiling.  
BAM/Hancock discourse thrives on “maybe they did it another way.”  
The lab should let players **propose, test, and publish** techniques — and fail them honestly under the same stone.

---

## 2. What players can create

| Layer | Player authors | Constrained by |
|-------|----------------|----------------|
| **Combo loadout** | Stack existing flags in novel order | Physics + budgets |
| **Variant** | Tweak parameters (ramp angle, capstan count, lube type) | Ranges |
| **New technique card** | Name + stages + required parts + claims | Must run in sim |
| **Full system** | Multi-station logistics chain (way + brakes + free sequence) | Scenario rules |

**Not allowed as magic:** delete mass, ignore friction, win without a reportable method string.

---

## 3. Technique card schema (shareable)

```
Name:
Author:
Parent flags: [list or none]
Stages: extract | free | way | haul | place
Parts needed: timber, rope, wedges, capstan, …
Claimed advantage:
Anomaly cost: 0–N
Result: pass/fail + budgets + gap tolerance
```

Export is the same shape as a normal win report — so invented methods compete with baseline on **evidence**, not lore.

---

## 4. Invent mode loop (Kerbal brain)

1. **Draft** technique card in notebook UI  
2. **Dry-run** on small mass (tutorial block)  
3. **Scale test** on trilithon or Hibla-class  
4. **Fail legibly** → edit card  
5. **Publish** to local album / share string  

Sandbox Director energy: poke the planet → here **poke the method**.

---

## 5. Léo-method link (what we derive)

| Léo-derived rule | In this lab |
|------------------|$|
| Everything has a **how it works** | Technique cards must specify stages/parts |
| Worn, believable mechanism | No chrome UI magic; timber/rope/stone language |
| Originality | Players invent; we don’t ship one “true lost tech” |
| Density without bloat | Catalog is finite; invention is infinite *combinations* |

We derive **rigor of explanation**, not any one creator’s IP or species designs.

---

## 6. Guardrails

- Invented techniques that only work with hidden cheats are invalid  
- Speculative physics = anomaly points + tagged report  
- Community sharing is optional; single-player invent mode is enough for v1

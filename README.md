# Impossible Structures Lab

**Working pitch:** A systems-honest construction sandbox where players try to **source, work, move, and place** materials to recreate historically “impossible” (or fiercely debated) megalithic builds — and see whether *any* combination of thinkable methods can close the gap.

Inspired by:
- Prior project **Kerbal energy** (finite kit, fail → revise → retry, rules are the puzzle)
- **BAM** (*Builders of the Ancient Mysteries*) — measured precision in ancient stonework; open engineering questions
- **Graham Hancock** (and related discourse) — the *question* of how and whether lost knowledge existed — **without the game endorsing one historical answer**

**Stance:** Engineering lab, not a verdict machine. Mainstream experimental archaeology and speculative methods are both *flags on the bench*.

**Repo:** https://github.com/24grabgo-lgtm/impossible-structures-lab

## Assessment — easiest structure / time / place for v0

| Candidate | Time & place | PoC fit |
|-----------|--------------|--------|
| **Stonehenge trilithon (2 uprights + lintel)** | Late Neolithic Britain, Salisbury Plain area | **Best overall** — complete wow unit, manageable count, rich docs |
| **Baalbek trilithon blocks** | Lebanon; Roman platform context, often debated | **Best pure logistics** — 3 blocks, extreme mass; abstract labor early |
| **Menga dolmen** | ~3800–3600 BCE, Spain | Strong “fit/engineering” puzzle; slightly less iconic globally |
| **Göbekli Tepe single T-pillar** | ~9600–8000 BCE, Turkey | Strong Hancock/BAM conversation hook; site data messier for full rebuild |
| **Puma Punku / Giza full** | — | **Not v0** — precision chaos / scale explosion |

### Locked PoC recommendation

| Axis | Choice |
|------|--------|
| **Structure** | **One trilithon** (not full Stonehenge circle) |
| **Time** | Late Neolithic **baseline toolkit** (~2500 BCE options); sandbox flags unlock later or speculative methods |
| **Place** | Short **quarry → plain → site** strip (sarsen/bluestone *material types*, not full Britain) |
| **Stretch** | Baalbek-scale single block after the trilithon loop works |

**Why this first:** Teaches the full loop — source → work → haul → erect → lintel — at masses that still feel human-scale-hard without requiring a city of workers abstractly on day one.
